## Описание программы

**GitHub User Finder** — это GUI-приложение для поиска пользователей GitHub, добавления их в избранное и сохранения списка избранных пользователей. Приложение использует официальное GitHub API для получения данных о пользователях.

### Возможности:

- ✅ Поиск пользователей GitHub по логину
- ✅ Отображение информации о пользователе (логин, ID, ссылка на профиль)
- ✅ Добавление пользователей в избранное
- ✅ Просмотр списка избранных пользователей
- ✅ Удаление пользователей из избранного
- ✅ Сохранение избранного в JSON-файл
- ✅ Автоматическая загрузка избранного при запуске
- ✅ Валидация ввода (проверка пустого поля поиска)
- ✅ Обработка ошибок API (пользователь не найден, нет интернета)
